# ProjectPilot v1.0.12

AI-assisted project delivery cockpit for managing projects, tasks, milestones, RAID items and release readiness.

## Deploy to GitHub Pages

1. Create a public GitHub repository, for example `ProjectPilot`.
2. Upload the included `index.html` and `README.md` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will publish the application at `https://YOUR-USERNAME.github.io/ProjectPilot/`.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
